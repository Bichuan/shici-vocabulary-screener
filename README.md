# 拾词 · 考研词汇筛查器

面向个人的考研英语词汇筛查工具。当前保留词库 5,220 词，已经全部接入八选一筛查。正确释义和七个干扰项都直接来自固定的原始词表，不编造额外中文内容。

## 本地启动

需要 Node.js 24.13 或更高版本。本项目已生成 package-lock.json，重新安装时使用 `npm ci`。

1. 在本目录打开 PowerShell。
2. 首次安装依赖：`npm ci`。
3. 导入固定词库：`npm run import:vocabulary`。
4. 启动：`npm run dev`。
5. 浏览器打开 **http://127.0.0.1:5173**。

以后使用时运行 `npm run dev` 即可，不需要重新下载词库。终端保持开启，按 Ctrl+C 停止。
启动端口固定；如果端口已占用会明确报错，不自动切换地址。后续本地学习存档绑定网站地址，不要混用 localhost 和 127.0.0.1。

也可以双击项目根目录的 `start-local.cmd` 启动本地服务，然后手动打开上述地址。

## Windows 桌面安装包

已生成 64 位 Windows 安装程序：`release/拾词-安装程序-0.3.0.exe`。双击后按当前用户安装，并自动创建“拾词”桌面快捷方式和开始菜单入口；安装后的应用完全离线运行，不需要 Node.js、浏览器或本地服务。

桌面应用将学习进度保存在自己的本地数据目录。浏览器版记录不会自动出现在桌面版中，需要先在浏览器版“错词与复筛”页面备份学习记录，再在桌面版恢复该 JSON 备份。卸载程序默认保留本地学习数据。

安装包目前没有商业代码签名证书，Windows 可能显示“未知发布者”或 SmartScreen 提示。项目代码更新后运行 `npm run package:win` 可重新构建安装包。

## 当前已实现

- Vue 3 + TypeScript + Vite 项目，桌面及窄屏词库页面。
- 原始 5,530 条词库，按用户确认清单排除 200 个基础词、50 个低频细分词和追加的 60 个低频生活场景词，应用使用剩余 **5,220 条**；支持英文、中文及其他拼写搜索、20 条分页、原顺序和字母排序。
- 原始 JSON、README、数据许可、完整来源提交和 SHA-256 固定快照。
- 可重复、无需联网的词库导入；校验空词、空释义、精确重复、大小写变体、序号、词频、字段类型、乱码、条目总数。
- 单词、学习记录、筛查任务的 TypeScript 数据契约。
- 数据校验报告以及关键导入边界测试。

- 5,220 个词全部生成八选一题目；正确项使用本词的原始释义，七个干扰项使用其他保留词条的原始释义。优先从相同分类选取并排除相同、明显重叠的释义，选项位置随机排列。
- 单词顺序按每 80 词一个区间随机处理，保留大致词频层次；区间内按首字母分组并交错抽取，尽量避免连续出现相同首字母。重新打开页面时未筛词顺序可再次变化；进度按稳定单词 ID 记录，已筛词不会重复计入。
- 桌面及移动端均可进入「单词筛查」，点击立即判题，正确选项与核心义显示 1 秒后自动切到下一题。反馈期间锁定答案，防止重复点击；键盘 Tab 聚焦、Enter / 空格提交。
- 顶部缩放控件支持 80%—150% 整页缩放，中间的百分比按钮恢复 100%；也支持 `Ctrl+-`、`Ctrl++` 和 `Ctrl+0`。缩放比例保存在当前浏览器或桌面应用本机，下次打开继续使用；打印时固定为 100%，不改变 A4 排版。
- 显示累计已筛选词数；错词自动保存，可展开查看单词和正确核心义。不显示错误次数、正确率或本轮统计，没有不确定选项。
- 初筛页面可随时下载“当前筛查备份”，文件名包含已筛词数和时间。备份不会中断或改变当前进度，用户可以继续筛选；也可以在确认后重置初筛及复筛记录，从新的随机顺序重新开始。备份文件可通过“错词与复筛”页面恢复。
- 切回词库或隐藏浏览器标签时暂停切题；返回后完整显示反馈 1 秒。最后一题反馈结束后显示完成状态，不自动重新开始。
- 答题记录包含稳定单词 ID、题目版本、词库版本、所选答案及正确核心义，已持久保存在 IndexedDB，供后续复筛和导出使用。

**进度和错词已自动保存到当前浏览器**：刷新、关闭网页或重启本地服务后，使用同一浏览器打开 `http://127.0.0.1:5173/#screening` 即可继续。错词复筛、导出和打印均已开放。

## 错词复筛

入口：`http://127.0.0.1:5173/#review`，桌面和移动导航均提供「错词与复筛」。

- 初筛未完成也能查看已保存的错词；完成全部 5,220 道初筛题后，才可开始复筛。初筛全部答对时显示空状态，不创建空任务。
- 「待复筛」显示最新一次结果仍为错误的历史错词；「历史错词」保留全部初筛错词及当前状态。答对仅改变待复筛状态，不删除历史记录。没有错误次数或正确率统计。
- 点击开始时固定全部待复筛词的顺序并持久保存新任务，避免答对移出列表后导致题目跳过。未完成的任务优先继续，不重复创建。下一次任务只包含上次仍答错的词。
- 复用八选一、选项洗牌、提交锁定、保存重试、反馈 1 秒、后台暂停和断点恢复逻辑。复筛不增加已筛选的唯一单词总数，不展示本轮完成数量。
- 复筛完成后返回列表查看结果，需要再次复筛时手动开始。答题时隐藏错词释义表，避免显示当前答案。
- 第一版仅从初筛错词逐步缩小待复筛范围，暂不主动将已经复筛答对的词重新加入任务；历史错词仍可供第 6 天导出。

## 本地存档规则

- IndexedDB 数据库 `shici-learning`，版本 1；`sessions` 对象仓库中的 `initial-screening` 保存完整初筛任务快照。无服务器、无登录、无云同步。
- 每次答题在一个读写事务中提交答题记录、版本和进度，事务成功后才显示已保存并开始 1 秒反馈。进度和错词由同一批记录推导，不分开写入。
- 反馈期间刷新或关闭，下次从下一道未答题开始；最后一道已保存后恢复为完成状态。未作答的词不会被跳过，已保存的词不会重复计入进度。
- 保存失败锁定当前题、保留本次选择并支持重试；尚未保存时离开页面会触发浏览器的离开提示（由浏览器决定是否显示）。看到“已保存”后可直接退出。
- 读取失败、未知存档格式、词库或题目版本不一致时暂停筛查，不自动覆盖或删除原存档。当前没有旧版持久存档需要迁移，后续更改结构时需显式迁移。
- 多个页面通过事务内版本比较防止旧进度覆盖新记录；发生冲突的页面提示刷新，以已成功保存的页面为准。
- 恢复备份会更新存储代次，已打开的旧页面不能覆盖恢复后的记录；确认恢复期间若另一个页面产生新记录，会取消覆盖并提示重试。恢复前的记录另存为 `before-restore`，供故障排查使用。
- 存档属于当前浏览器与网站地址；换浏览器、改端口或改用 localhost 无法读取同一份数据。清除网站数据会删除存档，隐私模式关闭后可能丢失数据。可通过第 6 天提供的备份文件恢复。
- 第 3 天的页面内存记录未写入磁盘，无法追溯恢复；第 4 天开始产生的答案自动持久保存。
- 第 5 天复用同一数据库和对象仓库，新增 `review-history` 键；不修改或清空第四天 `initial-screening` 存档，无需数据库结构升级。复筛任务及答案以一个历史快照事务提交，使用全局修订号防止多页面覆盖。

## 导出、打印与备份

入口位于 `http://127.0.0.1:5173/#review` 的「导出、打印与备份」区域。

- `导出 Excel CSV` 下载历史错词表，固定三列：序号、英文单词、正确核心义。文件使用 UTF-8 BOM、CRLF 和 CSV 引号转义，Windows Excel 可直接打开中文；可能被 Excel 当作公式的开头会自动转为文本。
- `打印背诵表` 打开独立的 A4 竖向打印页，每页分成三栏，按左栏从上到下、中栏从上到下、右栏从上到下排列。每栏只显示单词和释义，不显示序号与表头，每页最多安排 90 词，末页均衡分栏。点击「打印 / 保存为 PDF」后使用浏览器系统打印框，可直接打印或保存 PDF。
- 导出和打印采用历史错词：初筛答错的词始终保留，即使复筛已答对也不会从背诵表中消失。待复筛范围仍按最新复筛结果单独计算。
- `备份学习记录` 下载 JSON，包含初筛和复筛进度。`恢复备份` 只读取本机选择的 JSON，限制为 1 MB，先校验备份格式、当前词库版本、题目版本和答题记录，再要求浏览器确认；确认后在一个 IndexedDB 事务中替换初筛和复筛记录并刷新页面。取消、校验失败或写入失败均保留现有记录。
- 备份文件是唯一可跨浏览器或清除网站数据后恢复学习记录的方式。不要编辑 JSON 内容；更新词库或题目版本后，旧备份会被拒绝以防错误对应答案。

## 固定词库

来源：[exam-data/NETEMVocabulary](https://github.com/exam-data/NETEMVocabulary)。第三方按 2024 年考研英语（一）大纲整理，不能称为最新官方大纲。

详细来源在 `data/upstream/source.json`，原始说明和完整 CC BY-NC-SA 4.0 数据许可保留在同目录。衍生词库仍遵循该数据许可，保留归属与来源；题目的正确释义与全部干扰项都直接复制当前保留词条的原始中文释义。`src/domain/questionSamples.ts` 只保留旧版 48 题的顺序，用于兼容既有体验版存档，不再提供题目文字。

`npm run import:vocabulary` 首先校验原始文件 SHA-256，再生成 `public/data/vocabulary.json` 和 `data/reports/validation.json`。发现结构错误时返回失败，不生成新的应用词库。导入命令不会自行联网更新上游。

已确认的 200 词排除清单保存在 `data/config/excluded-basic-words.json`，每次重新导入和构建均会应用，不会恢复已删除词。原始词库、456 词审核表和 200 词候选表作为历史资料保留，其中“待审核”文字反映生成时状态；实际已生效的排除决定以此配置为准。`contentVersion` 同时包含原始提交和排除配置摘要，供后续学习任务绑定版本。

追加的 50 个低频细分词见 `data/review/已排除的50个低频词.md`，生效配置为 `data/config/excluded-rare-words.json`。如要恢复本轮 50 词，将配置中 `enabled` 改为 `false`，再执行 `npm run build` 并刷新页面；其他批次仍被排除。历史 240 / 447 词报告是排除这 50 词前的统计快照。

再从原最低频 447 词中追加排除的 60 词见 `data/review/追加排除的60个低频词.md`，配置为 `data/config/excluded-low-frequency-extra.json`。将该文件 `enabled` 改为 `false` 再构建，可以独立恢复这 60 词。三份配置均纳入版本摘要，累计排除 310 词，无重叠；原最低频 447 词中仍保留 337 词。

稳定 ID 由保留大小写的拼写生成，不依赖列表顺序。`may / May` 和 `march / March` 含义不同，分别保留。大小写提示不属于精确重复错误。当前检查只保证数据结构，**不代表中文释义和未来题目已经逐条审核**。

## 验证

- `npm test`：词库、题目、判题及存档测试。IndexedDB 测试使用 fake-indexeddb，涵盖事务提交、重开恢复、错误重试、多页面冲突和不兼容存档保护。
- `npm run test:e2e`：构建后，在独立浏览器环境中使用 48 词隔离测试词库运行完整流程，不读写用户 5173 地址的学习记录；全量 5,220 题的数据来源与结构由逻辑测试和构建检查覆盖。
- Windows 浏览器测试默认使用 `C:/Program Files/Google/Chrome/Application/chrome.exe`。其他安装位置可设置 `TEST_BROWSER_PATH` 为浏览器完整路径。测试输出放在 `test-results/`，其中备份、CSV、PDF 都是独立测试数据，不是个人学习记录。
- `npm run check:questions`：核对全部 5,220 道题与当前词库，生成 `data/reports/questions.json` 和 `data/review/全量题库抽查.md`。检查会拒绝原始词表之外的选项；结构检查仍不能完全识别近义词造成的语义歧义。
- `npm run typecheck`：TypeScript / Vue 类型检查。
- `npm run build`：重新校验导入、全量题库、类型检查和生产构建。
- `npm run preview`：在 http://127.0.0.1:4173 本地预览构建。此地址只作验收，今后日常筛查统一用 5173。

## 后续约定

只提供 8 个来自原始词表的释义选项；没有不认识 / 不确定入口。选择后反馈 1 秒自动下一题，答错记录词与正确释义，不统计错误次数。累计进度自动保存，支持历史错词复筛。打印词表只显示单词和正确中文释义。

全量题库已经生成；后续应继续抽查多义词和近义干扰项，发现歧义时从其他原始词条中更换干扰项。旧版 48 题记录会按单词和答题结果迁移后继续使用。当前导出格式是 CSV，可用 Excel 打开；纸质打印使用浏览器打印框，可选择打印机或保存 PDF。
