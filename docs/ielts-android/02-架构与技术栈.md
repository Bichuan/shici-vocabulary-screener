# 拾词架构与技术栈 · 雅思词汇与安卓支持

首版采用同一套 Vue 前端和 GitHub Pages 地址。雅思作为第三个独立词库接入；安卓通过可安装的网页应用（PWA）使用同一套筛查、复筛和备份逻辑。这个方案可以直接测试安卓浏览器与桌面图标两种入口，发布时继续走现有静态站点流程。

## 一、技术栈与改动位置

| 层 | 项目现状 | 本期设计 |
| --- | --- | --- |
| 词表构建 | Node.js ≥ 24.13、TypeScript；六级已有导入、排除和题目检查脚本 | 使用独立雅思快照及排除清单，复用词表结构和题目校验逻辑。构建输出独立的雅思 JSON。 |
| 前端 | Vue 3、TypeScript、Vite，使用 URL hash 切页 | 集中维护三套词库的显示名、资源路径、词库标识和加载器。首页选择后把当前词库传给既有组件。 |
| 学习记录 | IndexedDB 数据库 `shici-learning`；localStorage 记住所选词库 | 新词库分配独立存储键。初筛、复筛、恢复前副本、重置范围和备份校验均按词库隔离。 |
| 移动与离线 | Web App Manifest、构建生成的 Service Worker、Cache Storage | 安卓共用现有 App 身份和缓存机制；更新应用名称及安装引导，验证新增词包体积、首次下载和更新失败后的再次打开。 |
| 导出与打印 | 本地 JSON、Excel 可读的 CSV、打印 CSS 和浏览器打印 | 复用文件能力检测。安卓分别验证系统分享、浏览器下载、文件选择器和打印预览。 |
| 发布与测试 | GitHub Actions → GitHub Pages；Vitest、fake-indexeddb、Playwright；Windows 使用 Electron | 沿用静态部署。自动测试覆盖三套词库；安卓真机补测安装、离线、分享及系统打印。现有桌面应用继续使用共享前端。 |

## 二、从来源到题目

1. **固定来源。** 为雅思单独保存来源地址、版本或提交、文件校验值，以及覆盖英文和中文数据的许可说明。现有 `VocabularySource` 含 `syllabusYear`；若雅思资料没有大纲年份，允许该元数据缺省或采用明确的来源版本，同时维持旧词包兼容，避免填入虚构年份。
2. **构建词表。** 原始行经过拼写规范化、去重、基础词筛除、核心义选择，输出符合 `VocabularyBundle` 的静态文件。词 ID 根据词库内规范化拼写生成，不依赖数组顺序。记录每个删除或合并决定；一词多义保留可供排查干扰项的原始义项。若来源无词频，先检验可用的分层依据，再确定难度混排策略。
3. **生成并验题。** 词表提供核心义和干扰项候选。沿用现有出题逻辑，校验每题八项、中文去重、答案唯一标记及选项来源；人工复核近义、多义、变体造成的语义多解。构建校验失败时定位到具体词和选项。
4. **前端接入。** 可采用选择值 `ielts`、存储前缀 `ielts:` 和资源 `data/ielts-vocabulary.json`。内容版本随词表变化，题目版本随题目变化；学习与恢复使用项目已有版本校验。第三词库的载入失败只影响当前选择，可重试或切回其他词库。

## 三、老数据与更新

| 情形 | 处理 |
| --- | --- |
| 首次升级 | 保留考研词库标识 `netem-2024` 与历史无前缀键，保留六级标识 `cet6-2016-curated` 与 `cet6:` 键。沿用原有默认词库和已选词库。新增词库不触发其他词库的版本变更或重排。 |
| 切库、重置、恢复 | 先终止上一题的自动切题，切换后仅加载目标词库。写入时绑定产生该记录的词库；确认框注明目标词库。跨库文件在写入前拒绝，旧格式考研文件沿用既有识别规则。 |
| 手机更新 | 保留正式站点的协议、域名、路径及 manifest 的 id、scope、start_url。Service Worker 负责静态文件；学习进度由 IndexedDB 保存。刷新和缓存修复只处理应用资源。 |
| 发布失败 | 优先修正静态资源或回退到可用构建。用已存有三套测试数据的浏览器验证回退和再次升级，雅思入口暂不可见时仍保留已有雅思记录。 |

## 四、安卓侧实现与验证入口

- `src/App.vue`、`src/domain/learningNamespace.ts` 和 `src/domain/screeningStorage.ts` 是词库选择、存储隔离与恢复的主要入口。检查题库加载、选项切换和未完成写入之间的竞争。
- `public/manifest.webmanifest`、`scripts/generate-service-worker.ts`、`src/components/HomeDashboard.vue` 分别负责安装元数据、离线资源和使用引导。当前构建会枚举产物预缓存；测量加入雅思前后的冷启动、缓存耗时和大小，缓存就绪后再提示可离线。
- 安卓安装引导按设备展示。在 Chrome 打开链接，按浏览器可用菜单选择「安装应用」或「添加到主屏幕」；安装入口不可用时保留网页使用路径。真机验证图标启动、触控状态、系统返回、文件选择与恢复。安装操作可参考 [Chrome 安卓网页应用帮助](https://support.google.com/chrome/answer/9658361?co=GENIE.Platform%3DAndroid&hl=zh-Hans)。
- `src/domain/fileTransfer.ts`、`src/components/PrintSheet.vue` 沿用现有文件输出及排版。真机检查分享或下载得到的文件能重新选中；另用跨多页错词样本验证打印与保存 PDF。
