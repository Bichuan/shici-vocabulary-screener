# 拾词需求文档 · 雅思词汇与安卓支持

本期交付两项能力：学习者可以单独筛查雅思词汇；安卓用户可以从现有拾词网址开始学习，首次缓存完成后可以离线继续。现有考研 5,220 词和六级 4,719 词是升级验收的基线。

## 一、雅思词汇怎么选

| 决策 | 首版要求 |
| --- | --- |
| 学习范围 | 首页新增「雅思词汇」。优先收录雅思学习中通用的词和常见学术语境用词。对外标注实际来源、版本和收录数量。 |
| 来源 | 选取允许在公开项目中分发英文词条及对应中文释义的资料。先核验来源、看样本，再确定收录量。 |
| 基础词 | 参考此前的基础词清单生成候选。例如 a、an、the、apple 在来源中且只考查日常基础义时，可列入排除候选。逐项保留原词、原义和理由，方便复核。 |
| 熟词生义 | 如 address 表示「处理」、issue 表示「议题」，即使拼写常见也值得保留。判断依据是来源中实际考查的词义。与考研、六级重合的词仍可独立收录。 |
| 删除尺度 | 这次只指定了基础词筛除。六级项目的删除数量不作为雅思配额；低频本身也不构成删词理由。首版词数以去重、筛除和题目校验后的实数为准。 |
| 题目质量 | 每个英文词配一个简洁核心义和七个不同的干扰项，八项均可追溯到同一份雅思来源。干扰项与该词其他常见义也要核对；出现两个合理答案即换项重审。 |

## 二、用户怎么用

1. 打开拾词，选择「雅思词汇」。首次进入显示新进度，再次打开可从上次位置继续。切回考研或六级，仍能接着原来的词和轮次筛查。
2. 每题显示英文词和八个中文选项。点选后显示正确项约一秒，自动进入下一题。保留首字母交错和难度混排；下一题的按钮恢复初始颜色。
3. 答错的词进入当前词库的错词记录。可连续复筛三至四轮或更多轮，导出时可选「历史错词」或「当前仍不会」。保留累计筛查进度；不增加错误次数或「不确定」选项。
4. 延续 CSV、JSON 备份与恢复，以及 A4 每行三组英汉词对、两条竖线的打印布局。重置前确认，操作范围限于当前词库。
5. 安卓用户通过现有 HTTPS 链接用浏览器学习；首版优先验收安卓版 Chrome。安装入口可用时，可将拾词添加到主屏幕。首次联网打开并完成离线缓存后，从图标打开也可继续学习。
6. 记录跟随当前设备和浏览器的本地存储。用户希望把学习进度带到另一台设备时，可导出对应词库的 JSON，再到目标设备选择同一词库恢复。安卓首版沿用网页版，无需注册、云同步或应用商店账号。

## 三、发布验收

| 场景 | 通过条件 |
| --- | --- |
| 词库和题目 | 能用固定来源重建同一份词表；发布词条均能出题。全量检查八个不同选项与来源，人工复核易混义，已发现的多解题全部修正。 |
| 老用户升级 | 使用测试存档模拟考研接近筛完、六级正在复筛。升级前后逐项对照累计数、下一词、错词集合和复筛轮次；无词库标识的旧考研备份仍可按原流程恢复。 |
| 多轮复筛 | 用四个已知错词做三轮，预先指定每轮答对哪些。最后把「当前仍不会」与预期词 ID 逐项核对，CSV 与打印内容一致，历史错词仍可单独导出。 |
| 安卓真机 | 从浏览器链接和主屏幕图标分别启动；测试答题、退出续筛、飞行模式冷启动、文件备份与恢复。升级后能读回原记录；记录机型、系统及浏览器版本。 |
| 输出文件 | 中文 CSV 在 Excel 打开正常；JSON 可以恢复相同进度；A4 多页预览无截词或隔页大段空白。在支持系统打印的安卓设备上实测 PDF 输出。 |
