# 拾词实施清单 · 雅思词汇与安卓支持

执行记录见 [本地验收记录](04-本地验收记录.md)。本次按本地回归结果直接发布。安卓真机和 A/B 验证另行安排。

| 步骤 | 前置 | 要做什么 | 完成标志 |
| --- | --- | --- | --- |
| ☑ 01 建立升级基线 | 无 | 用独立浏览器配置建立测试记录：考研接近完成、六级正在复筛。另保存旧格式考研 JSON、当前备份和预期下一词。 | 可重复还原样本；已列出每库的进度、错词、复筛轮次、下一词和导出结果。测试全程使用样本数据。 |
| ☑ 02 选定雅思来源 | 无 | 比较来源覆盖、英文和中文许可、可追溯版本、核心义质量、可用分层信息。抽取约 50 词，列出保留、排除和存疑样例。 | 形成可公开分发的来源说明及样例；如来源只授权英文，先解决中文释义授权再使用该来源。 |
| ☑ 03 筛除基础词 | 02 | 规范化并去重，与既有基础词候选表交叉；逐项复核原义，保留熟词生义。 | 产出排除清单和保留例外，各有词、义、理由。原始行数可与合并、无效、排除和最终保留数核对。 |

| ☑ 05 接入第三词库 | 01、04 | 首页加「雅思词汇」，接入加载器、存储命名空间、备份校验；复用初筛与多轮复筛、CSV、打印及重置。 | 建立三套不同进度，快速切库、重开、重置雅思和尝试跨库恢复，考研、六级基线逐项一致。 |
| ☐ 06 摸底安卓现状 | 01，可与 02–05 并行 | 在安卓 Chrome 真机用现有版本测浏览器启动、主屏幕安装、第二次打开、断网续筛、下载及文件选择。 | 记录机型、系统、浏览器、入口和可复现的问题；列出已经可用的能力及需要修复的具体项目。 |
| ☐ 07 完成安卓适配 | 05、06 | 修正安装文案和已复现的问题；确认新版预缓存包含雅思资源，处理首次下载被中断、分享不可用等情况。 | 同一 HTTPS 测试地址上，真机首次联网就绪后三库均可离线使用；中断更新后恢复联网能继续，并读回既有进度。 |
| ☐ 08 全流程回归 | 05、07 | 跑类型检查、单元测试、生产构建和端到端测试。在安卓主屏幕入口做三轮错词复筛、导出当前仍不会、JSON 恢复及多页打印。用 iPhone、桌面浏览器和现有 Windows 入口复查受影响功能。 | 验收记录含环境、预期与实测。用相同测试样本核对错词集合、CSV、打印内容及恢复进度；确认旧考研备份仍可导入。 |
| ☐ 09 发布与上线复核 | 08 | 更新词库来源和安卓使用说明；按现有 Pages 流程发布。在正式子路径检查首页、JS、CSS、manifest、Service Worker 和三个词包，随后真机从桌面图标启动新版。 | 首页和依赖返回正确内容，线上联网及离线各答题一次，重开可续筛。若出现白屏、错词库写入或档案不兼容，停止推广并按架构文档回退验证。 |
