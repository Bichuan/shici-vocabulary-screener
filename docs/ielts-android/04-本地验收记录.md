## 06–08 移动端和 Windows

安卓按现有 Chrome 网页应用路线适配。保留 manifest 的 `id`、`scope`、`start_url`、名称和主屏幕图标，更新项目描述与安卓安装说明。加入雅思后，预缓存增加约 1.28 MB 词包。Windows Electron 使用独立用户目录启动，验证能读取考研词库并访问 IndexedDB。

在桌面 Chrome 的 Pixel 7 移动模拟中，旧版可联网使用、缓存并离线答题，首页原先显示 iPhone 的安装路径。新版可展示安卓安装指引，离线切换三套词库，并在离线作答后重开、下载 JSON 再导入。按正式站点的子路径模拟更新中雅思词包返回 404，旧版在断网时仍能从 1 / 5,220 的进度继续。恢复资源后，从刷新入口完成更新，再次断网时新版可继续使用。

生产构建、63 项单元测试、原有 18 项端到端用例及 3 项雅思与安卓专项用例已通过。雅思四个错词完成三轮复筛后，CSV 和 A4 打印均只包含预期的唯一待复筛词。

后续安卓真机验收需完成下列操作，记录机型、系统及 Chrome 版本。

1. 打开测试地址，按 Chrome 菜单安装，从主屏幕打开一次。
2. 等待缓存完成，开启飞行模式，从主屏幕冷启动。切换三套词库，筛一词，重开确认进度。
3. 下载或分享 JSON，用系统文件选择器打开它并恢复。完成跨页 A4 打印或保存 PDF。
4. 使用已有测试档案升级，在更新尚未完成时断网一次，再联网完成更新，核对进度。
