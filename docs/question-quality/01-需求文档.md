# 拾词需求文档 · 八选一释义去重

## 目标

用户看到一个英文词和八个中文选项时，应能选出唯一合理的核心义。其余七项都来自当前词库的原始释义，彼此意思也应有足够区分。考研、六级和雅思的初筛与复筛都适用。

## 已发现的问题

| 问题 | 当前证据 | 优先级 |
| --- | --- | --- |
| 正确项和某个干扰项都能解释目标词 | 考研 `watch` 同时出现「观看」和「看」。`contain` 同时出现「包含」和「包括」。 | 优先修复，因为用户可能被误判为答错。 |
| 两个干扰项共享义项 | 考研 `anticipate` 同时出现干扰项「建造、创立」和「创立、建立」。按中文分隔符拆分，考研 104 题、六级 88 题命中，雅思 0 题命中。 | 清理八项中的重复义项，确保干扰项有区分。 |
| 选项文字完全重复 | 三套词库共 14,908 道题，按现有文字规范化规则检查，命中 0 题。 | 纳入持续全量校验。 |

104、88 和 0 是共有义项的自动扫描结果。近义表达、熟词生义、上下位概念和词性差异还需要人工判断。考研已做过 BIC-22 分层抽查，这次沿用该方法，并将六级和雅思纳入同一套检查。[BIC-22 抽查记录](../../data/review/BIC-22-语义抽查.md)

## 功能要求

| 编号 | 要求 |
| --- | --- |
| R1 | 每题显示一个英文词、一个可辨认的正确核心义和七个干扰项。正确项继续使用该词在词库中已选定的核心义。 |
| R2 | 生成题目时比较正确项与所有干扰项。存在另一种写法也能解释该词、涵盖其常见其他义项，或经复核可同样判对时，换入来自同词库的选项。 |
| R3 | 比较八项中的每一对。规范化后文字相同、共享清晰的独立义项，或经复核在本题中表达同一意思时，替换需要调整的干扰项。 |
| R4 | 延续首字母交错、难度混排、选项打乱和约一秒答题反馈。继续使用现有初筛、复筛、备份、CSV 和打印入口。 |
| R5 | 升级后按原词库读取累计进度、历史错词、待复筛词及轮次。旧版已答题保留当时选项和判定，更新后的题目用于后续作答。旧 JSON 按原先适用的词库恢复。 |

## 验收标准

- 三个词库仍能生成 **5,220 道考研题、4,719 道六级题和 4,969 道雅思题**。全量验证每题八项、唯一正确标记、来源可追溯、两两无规则范围内的重复。遇到无法凑足八项的词，构建应报出词条和原因。
- 复查 `watch`、`contain`、`anticipate` 等已复现案例，以及原扫描命中的 192 道题。按频率层和首字母抽样复核三库，另检查多义词、已经替换的选项和用户曾反馈的题。验收记录注明抽样范围与已处理的歧义。
- 用模拟存档分别检查初筛未完成、首轮复筛中、多轮复筛完成以及旧 JSON 恢复。比对升级前后的已答词、错词集合、轮次及导出内容，确认可以继续答题。
