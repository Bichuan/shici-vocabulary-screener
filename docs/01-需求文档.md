# 拾词 · 项目需求文档

拾词是面向考研、大学英语六级和雅思学习者的英语词汇筛查工具。用户逐词判断核心义，把自己还不熟悉的词筛出来，经过多轮复筛缩小范围，再导出或打印成背诵表。

## 一、产品范围

| 使用入口 | 当前交付 |
| --- | --- |
| 网页 | 浏览器可直接使用三套词库。[正式站点](https://bichuan.github.io/shici-vocabulary-screener/) |
| 手机 | iPhone 和安卓通过网页使用，可按首页指引添加到主屏幕。首次联网完成缓存后可离线筛查。新版安卓能力已在浏览器模拟环境验证，真机系统操作待补验。 |
| Windows | 已发布 x64 安装包 v0.4.0，包含考研和六级。支持桌面快捷方式、离线使用和界面缩放。新版三词库安装包有独立的打包及验收任务。[下载页](https://github.com/Bichuan/shici-vocabulary-screener/releases/latest) |

学习记录保存在用户实际使用的设备、浏览器或桌面应用里。跨设备转移通过对应词库的 JSON 备份与恢复完成。产品当前使用本地存储，无注册、登录和云同步流程。

## 二、核心用户流程

| 编号 | 功能 | 用户操作与结果 |
| --- | --- | --- |
| R1 | 选择和浏览词库 | 选择考研、六级或雅思。可搜索英文、中文和其他拼写，查看原顺序或按字母排序，并查询词库来源及许可。再次打开时可继续使用已选词库。 |
| R2 | 八选一初筛 | 一次展示一个英文词和八个中文选项。正确项使用一个简洁的核心义，七个干扰项取自同词库。点选后显示正确项约一秒，再自动进入下一题。题序按难度分层和首字母交错。 |
| R3 | 自动保存与续筛 | 按词库显示累计筛查进度。作答写入成功后才进入反馈和切题，答错自动记入错词。退出或重开可接着做未答题。遇到保存失败时保留当前选择供重试。 |
| R4 | 初筛错词与多轮复筛 | 可随时查看初筛错词。完成当前词库初筛后开启复筛，未完成的轮次可继续。答对的词从待复筛列表移出，历史错词仍可查看。后续轮次继续筛当前仍不会的词。 |
| R5 | 备份、恢复和重置 | 支持保存当前筛查备份，也可备份完整学习记录。恢复时校验词库与版本，先预览再确认。重置需确认，作用于当前词库。不同词库可以各自保留进度与复筛轮次。 |
| R6 | 导出背诵表 | 选择「全部历史错词」或「当前仍不会的词」。CSV 可用 Excel 打开。打印使用 A4 竖版，每行三组英汉词对，以两条竖线分隔，按完整行跨页。用户可直接打印或从系统打印界面保存 PDF。 |
| R7 | 移动端与访问恢复 | 首页提供 iPhone 和安卓主屏幕安装指引。应用内可刷新检查更新。访问拾词目录下的无效链接时，404 页面提供返回首页、复制反馈信息和 GitHub 反馈入口。 |

界面以筛查为主。答题时展示目标单词和选项，反馈结束后清除上一题选中状态。进度展示累计已筛查词数，错词记录供复筛与导出。选项全部用于八选一作答。

## 三、词库规则

| 词库 | 选词依据 | 网页题量 |
| --- | --- | ---: |
| 考研 | 第三方按 2024 年考研英语（一）大纲整理的固定词表。原始 5,530 条，排除 200 个基础词和 110 个低适用性词。 | 5,220 |
| 六级 | 第三方按 2016 年修订版四六级大纲整理的合并词表。原始 5,278 条，排除 437 个基础词和 122 个低适用性词。 | 4,719 |
| 雅思 | ECDICT 雅思标签固定快照。原始 5,040 条，排除 71 个基础词，保留有常见进阶义的熟词。 | 4,969 |

词源、版本、许可和排除清单需可追溯。三库共 14,908 道题，每题的八项文字去重已通过。正确项必须在语义上唯一，干扰项也应有区分。已发现的 `watch`「观看／看」等案例列入下一轮修复。[释义去重专项](question-quality/01-需求文档.md)

## 四、总体验收

1. 在三套词库分别筛词并答错一题。切库、刷新、退出后重开，核对各库进度和错词。
2. 用含四个错词的样本完成三轮复筛。比对历史错词与当前待复筛词，确认 CSV 和打印范围一致。
3. 导出并恢复旧 JSON。核对已有初筛、未完成复筛和历史选项。错库文件、取消确认、并发写入失败都应保全存档。
4. 在浏览器和主屏幕入口验证缓存完成后离线续筛。在 Windows 打包验收时核对安装、离线启动、缩放与原记录读取。打印样本需跨多页，确认每行完整。
5. 从真实 404 返回首页，检查反馈能复制并继续原进度。每次正式发布复查首页、词包和离线资源。
